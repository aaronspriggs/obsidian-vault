# Raspberry Pi wall panel configured with TouchKio and HA automations

Set up RPi (hadashboard) as wall-mounted kiosk running TouchKio. Created Wall Panel Lovelace dashboard, MQTT Dashboard HA user, brightness control bridge script/service, dim timer (60s), screensaver timer (10min), and key automations: Wake on Activity, Dim After Idle, Screensaver After Idle, Morning Wake at 7am.
